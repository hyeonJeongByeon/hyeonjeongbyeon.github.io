  <div class="p-label">Summary</div>
  <div class="p-value">
This project explores a Virtual Study Assistant (VSA) that uses generative AI to improve accessibility and participation in research studies, particularly for historically underrepresented populations. The bilingual (English–Spanish) chatbot supports recruitment, inquiries, and screening while reducing the labor required for translation and adaptation. Designed in collaboration with translational health teams, the system critically examines how AI-driven language support can expand access without reinforcing
existing biases or inequities.
